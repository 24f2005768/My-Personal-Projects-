UAT Cheat Sheet

Universal Approximation Theorem

One hidden layer + a nonlinearity can fit any continuous function on [a, b] if it's wide enough. Training still has to find the weights.

01The idea

f̂(x) = b + Σi=1..n wi · σ(vix + ci)
  • Existence ≠ learnable. UAT promises good weights exist. It says nothing about gradient descent finding them or about generalizing.
  • Nonlinearity is required. Linear ∘ linear = linear, so stacked layers with no activation act as one layer.
  • Width = bends. n ReLU units give at most n + 1 straight pieces.
  • Regression output: no final activation, loss = MSE.

02Setup + data

import numpy as np
import matplotlib.pyplot as plt
import torch, torch.nn as nn
torch.manual_seed(42); np.random.seed(42)

def target(x):   # 3 frequencies
    return (np.sin(2*np.pi*x) + 0.5*np.sin(6*np.pi*x)
            + 0.3*np.cos(10*np.pi*x))

x = np.linspace(-1, 1, 500, dtype=np.float32)
x = x.reshape(-1, 1)
X, y = torch.tensor(x), torch.tensor(target(x))

Inputs must be shape (N, 1) and float32.

03Model

class Net(nn.Module):
    def __init__(self, n=20, act=torch.relu):
        super().__init__()
        self.h = nn.Linear(1, n)  # in → hidden
        self.o = nn.Linear(n, 1)  # hidden → out
        self.act = act
    def forward(self, x):
        return self.o(self.act(self.h(x)))

# same thing, one line
net = nn.Sequential(nn.Linear(1, 20), nn.ReLU(),
                    nn.Linear(20, 1))

04Training loop

opt = torch.optim.Adam(net.parameters(),
                       lr=0.01)
loss_fn = nn.MSELoss()
net.train()
for step in range(3000):
    opt.zero_grad()
    loss = loss_fn(net(X), y)
    loss.backward()
    opt.step()
net.eval()
with torch.no_grad():
    pred = net(X).numpy()
  1. zero_grad() clears old gradients (they add up otherwise)
  2. net(X) forward pass, then the loss
  3. backward() computes every ∂L/∂θ
  4. step() updates θ ← θ − α·∇L
  5. eval() + no_grad() for predictions

05Width sweep more = better

for n in [2, 5, 20, 100]:
    torch.manual_seed(42)
    pred, mse = train(Net(n))

ReLU, Adam lr=0.01, 3000 steps. Gains flatten after ~20 neurons.

07Deep vs wide

def deep(width=10, depth=6):
    layers = [nn.Linear(1, width), nn.ReLU()]
    for _ in range(depth - 1):
        layers += [nn.Linear(width, width),
                   nn.ReLU()]
    return nn.Sequential(*layers,
                         nn.Linear(width, 1))

n_params = sum(p.numel()
               for p in net.parameters())

Each layer bends the previous layer's bends, so depth multiplies pieces. Count before you claim savings: wide 100×1 = 301 params, deep 10×6 = 581.

10One ReLU neuron

out = w * np.maximum(0, v*x + c) + b

v slope + direction · c moves the kink · w scales or flips · b lifts. A net is a sum of these ramps.
